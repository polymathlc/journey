# 《西游记：大闹天宫与通臂之决》 (Journey to the West: Havoc in Heaven)

一款基于 HTML5 Canvas + Web Audio API 打造的纯正《西游记》180重天神魔动作肉鸽（Roguelite）单文件网页游戏。

---

## 🎮 快速开始 (How to Play)

### 方法一：本地直接游玩 (Local Browser)
直接双击打开项目根目录下的 **`index.html`**，即可在任意现代浏览器（Chrome、Edge、Safari、Firefox）中流畅游玩！全部美术与音效已内嵌，无需配置任何服务器环境或依赖。

### 方法二：GitHub Pages 网页托管 (GitHub Pages Deployment)
1. 将本项目推送到你的 GitHub 仓库。
2. 进入仓库的 **Settings** -> **Pages**。
3. 在 **Build and deployment** 下将 **Branch** 设置为 `main`（或 `master`），目录选择 `/ (root)`，点击 **Save**。
4. 稍等片刻，即可通过 GitHub 提供的公开网址直接在线畅玩！

## 👹 六大阶段 180 重天首领战 (Boss Encounters)

- **第 30 重天**：**盘丝洞·蜘蛛精七仙姑**（毒丝缠绕、酸液毒池、蜘蛛集群）
- **第 60 重天**：**白虎岭·白骨精三变夫人**（三阶段变化幻身、九幽冥火、地脉骨刺）
- **第 90 重天**：**平顶山·金角大王与银角大王**（双首领协同、七星宝剑、紫金红葫芦吸附）
- **第 120 重天**：**灌江口·二郎显圣真君杨戬与哮天犬**（三尖两刃枪、天眼极光柱、哮天犬扑咬）
- **第 150 重天**：**西天大雷音寺·大日如来佛祖**（五指如来金光掌、万字佛印、五行山压制）
- **第 180 重天**：**混世魔猴·通臂猿猴（最终决战）**（一阶段暗影武道，二阶段狂暴魔猿真身）
- **第 180 重天之后**：**无尽混元轮回试炼**，首领属性无限攀升！

## 🛠️ 项目文件结构 (Files)

- `index.html`：**完全自包含的单文件游戏**（内嵌所有 108 式神通、音频合成器与 Base64 精美美术）
- `build_full_jttw_game.py`：构建与编译游戏主文件的 Python 脚本
- `assets_webp/`：包含所有高清 WebP 游戏原画与精灵图切片
- `test_game.py`：自动化完整性测试套件
